# 🎮 Battle Arena

A 2D browser-based survival game built using HTML, CSS and JavaScript.

## ✨ Features

- 🗺️ Large scrolling map
- 🏠 Buildings and obstacles
- 🎯 Enemy AI
- ❤️ Health system
- 🟢 Battle Royale safe zone
- 📱 Mobile touch controls
- 🔄 Restart functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas API

## 🚀 How to Play

1. Open `index.html` in a browser.
2. Use the joystick to move.
3. Use the FIRE button to attack enemies.
4. Stay inside the safe zone.
5. Survive and defeat all enemies.
